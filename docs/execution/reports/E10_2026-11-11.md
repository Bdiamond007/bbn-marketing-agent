### Chaîne de traitement

1. **Téléversement** : déclaration du type (liste blanche) et de la taille (≤ 20 Mo), puis URL signée PUT de 15 minutes vers une clé de quarantaine du tenant.
2. **Finalisation** : la déclaration de droits est obligatoire. Le média passe ensuite par :
   - l'analyse antivirus ;
   - le décodage pour obtenir le type réel, qui doit correspondre au type déclaré ;
   - les limites : 40 mégapixels, 12 000 px par côté ;
   - le réencodage : rotation EXIF appliquée, métadonnées supprimées.
3. **Résultat** :
   - **ready** : empreinte SHA-256, dimensions et droits enregistrés ;
   - **rejected** : raison expurgée.

   Le fichier de quarantaine est supprimé dans les deux cas. Aucune transaction SQL ne reste ouverte pendant le décodage.
4. **Consultation** : URL signée GET de 5 minutes, seulement pour un média prêt du tenant.
5. **Publication** : `assertMediaPublishable` exige le statut ready, des droits déclarés et l'appartenance au tenant. Elle sera utilisée par E16 et E18.
